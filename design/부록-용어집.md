# 부록 용어집

> 작성 전

이 문서에서 쓰는 용어의 뜻.

## 담을 내용

- [ ] claim · 사람 락 · 실행 가능 판정(계획 승인 · 최신 작업 순서 포함)
- [ ] Token Budget · `estimated` · `attempt` · `actual` · `commits`(트레일러 합계, 최상위 ADR-021로 출처가 없어짐) · `session`
- [ ] admit · attach · retire · 허가
- [ ] 시그니처 스텁 · pending 테스트(decision-11, 앞으로 새로 만들지 않음)
- [ ] AC 하나씩 TDD · 비즈니스 규칙(`B<k>`) · 테스트 표식(`<카드 ID>#<n>` · `<카드 ID>#B<k>`)
- [ ] 최상위 부록 용어집에서 이어받는 용어 — 계획 승인 · 승인 게이트 · `humanSigners` · 작업 순서 · 단계별 커밋 · 토큰 계량 컴포넌트(이름 미정). 뜻은 옮겨 적지 않고 최상위 부록 용어집을 가리킨다
