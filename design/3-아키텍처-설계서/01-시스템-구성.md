# 3.01 시스템 구성

agent-orchestrator는 단일 JVM 프로세스이고, `com.coralstay.orchestrator` 아래 진입점 `Main`과 일곱 패키지로 나뉜다 — 패키지 하나가 최상위 3.03 §1의 오케스트레이터 구성 요소 하나 또는 포트 하나를 맡는다.

## 패키지 지도

| 패키지 | 클래스 | 책임 | 구현 상태 | 테스트 |
| --- | --- | --- | --- | --- |
| (루트) | `Main` | CLI 진입점. 인자를 `run <taskId>` 한 형식으로만 해석한다. 잘못된 인자는 사유와 usage를 stderr에 쓰고 종료 코드 2. `parse`는 부수효과 없는 순수 함수, `System.exit`은 `main`에서만 부른다 | 구현 | `MainTest` |
| `backlog` | `BacklogClient` | backlog.md CLI(`backlog task view <id> --plain`)를 감싸 제목 · 상태 · AC · 직접 의존을 `Task` 값으로 읽는다. `isRunnable`은 `status = To Do` ∧ 직접 의존 전부 Done일 때만 참이다. 외부 명령 실행기 `processExecutor`(stdout · stderr 동시 읽기)를 함께 제공한다 | 구현 | `BacklogClientTest` |
| `workspace` | `WorktreeManager` | 태스크별 `../<repo>-wt/<id>` worktree와 `task/<id>` 브랜치를 만들고 지운다. 경로 · 브랜치가 이미 있으면 아무것도 바꾸지 않고 실패한다. 지울 때 `--force`를 쓰지 않아 미커밋 변경이 있으면 worktree가 남는다. 태스크 ID는 영숫자 · `-` · `_`만 허용한다 | 구현 | `WorktreeManagerTest` |
| `spawn` | `AgentSpawner` | `claude -p <prompt> --permission-mode <mode> --permission-prompts none`을 띄우고 핸들(`SpawnedAgent`)을 바로 돌려준다. stdin은 즉시 닫고 stdout · stderr는 virtual thread로 끝까지 읽는다. 제한 시간이 지나면 `terminate`로 자손까지 끝낸다. `terminate`는 자손 목록을 먼저 떠 두고 destroy → 유예 → destroyForcibly 순으로 종료하는 단일 구현이다 | 구현 | `AgentSpawnerTest` |
| `registry` | `SessionRegistry` | 살아 있는 세션을 추적하고 동시 실행 수를 공정 `Semaphore`(기본 용량 1)로 제한한다. 호출 순서는 `admit → attach → retire`다. `retire`는 프로세스 종료 → 제거 → 허가 반납을 한 호출로 하고, 제거에 성공한 호출만 허가를 반납해 멱등이다. 같은 태스크의 중복 admit은 거부한다 | 구현 | `SessionRegistryTest` |
| `agent` | `AgentRunner`, `AgentRunner.ClaudeCodeRunner` | 에이전트 실행 포트. "띄우고 기다려 결과를 받는다"만 약속한다. 결과 `AgentRun`은 종료 코드 · 출력 · 타임아웃 여부와 헤드리스 JSON에서 읽은 세션 총량(`Session`, `Tokens`)을 담는다. Claude 구현은 `--model`과 `--output-format json`, `--disallowedTools "Bash(git push:*)"`를 붙인다 | 시그니처 스텁(`pending: DRAFT-3`) | `AgentRunnerTest` |
| `policy` | `AllocationPolicy`, `DefaultAllocationPolicy` (설계) / `ModelPolicy` (현재 코드) | 예상 `in+out`으로 모델을 고른다. 설계는 정책 확장 지점 `AllocationPolicy` 인터페이스 하나와 내장 `DefaultAllocationPolicy`(토큰 구간 · 모델 이름은 클래스 상수)다. 구현 선택은 `-Dpolicy.class=<FQCN>` → `ServiceLoader.load(AllocationPolicy.class)`(정확히 하나면 그것, 둘 이상이면 시작 거부) → 내장 기본 구현 순이다 (decision-12). 현재 코드는 decision-10 기준 `ModelPolicy` 시그니처 스텁이고, `AllocationPolicy`로 바꾸는 일은 DRAFT-4가 맡는다 | 시그니처 스텁(`pending: DRAFT-4`, `ModelPolicy`) | `ModelPolicyTest` |
| `card` | `TaskCardSource` | 카드 접근 포트. 카드를 읽고 검증하고, claim · `attempt n` · `actual`을 기록한다. 상태 전이와 `### Token Budget` 파싱 · 출력은 값 타입(`Card` · `TokenBudget` · `Tokens`)에 두고, 구현체는 저장 · 커밋만 맡는다 | 시그니처 스텁(`pending: DRAFT-1`) | `TaskCardSourceTest` |

시그니처 스텁은 공개 API만 있고 본문이 `UnsupportedOperationException("pending: <카드>")`를 던진다. 그 테스트는
`@Tag("pending")`이라 `./gradlew test`에서 빠지고 `./gradlew pendingTest`로 돈다 (1.02 P2).

## 패키지 의존

![agent-orchestrator 패키지 의존 — 실선은 패키지 간 import, 점선은 외부 프로세스 호출, 점선 테두리는 시그니처 스텁](../diagrams/01-packages.svg)

- 패키지 사이 import는 둘뿐이다. `workspace → backlog`(외부 명령 실행기 `processExecutor`와 결과 `ProcessResult`를 함께 쓴다), `registry → spawn`(회수가 `AgentSpawner.terminate`를 쓴다 — 타임아웃 처리와 회수의 종료 구현은 하나다).
- 포트 패키지(`agent` · `card` · `policy`)는 다른 패키지를 import하지 않는다. 코어가 포트에 의존하고, 포트가 코어에 의존하지 않는다.
- `Main`은 아직 어느 패키지에도 의존하지 않는다. `run` 흐름의 배선은 실행 흐름을 한 클래스에 모으는 자리(최상위 3.03 §1의 `RunCommand`)가 맡는다 (decision-2).
- 외부 의존은 프로세스 호출뿐이다. `backlog` → backlog CLI, `workspace` → git, `spawn` · `agent` → `claude`. 외부 프로세스 실행은 `Function<List<String>, ProcessResult>` 실행기나 실행 파일 경로로 주입받아, 테스트는 가짜 실행기 · 셸 스크립트로 바꾼다.
- `agent.AgentRunner`는 `spawn.AgentSpawner`를 Claude 구현으로 옮겨 받을 자리다 (decision-7). 두 패키지에 같은 모양의 결과 · 핸들 타입(`AgentResult` · `AgentRun`, `SpawnedAgent` · `RunningAgent`)이 있고, `agent.AgentRunner.Tokens`와 `card.TaskCardSource.Tokens`도 같은 모양이다 — 하나로 합칠 대상이다.

## 최상위 구성 요소와의 대응

최상위 3.03 §1의 오케스트레이터 구성(최상위 다이어그램 `09-orchestrator`의 노드)과 이 저장소의 패키지 · 최상위 요구사항의 대응이다.

| 최상위 구성 요소 | 이 저장소 | 최상위 요구사항 | 비고 |
| --- | --- | --- | --- |
| Board Watcher | `backlog.BacklogClient` | ORC-005 · ORC-025 | 판독과 실행 가능 판정(`isRunnable`)만 있고 감시 루프는 없다 (1.02 P10, `TBD(최상위 Q-10)`) |
| Request Queue | — | ORC-006 · ORC-007 | 패키지 없음. 단발 실행이라 큐가 없다 |
| Dispatcher | `registry.SessionRegistry`의 `Semaphore` | ORC-008 · ORC-026 | 동시성 허가만 있고 워커풀 · 전용 슬롯은 없다. 허가 수 기본 1 |
| Allocation Policy | `policy.AllocationPolicy` · `DefaultAllocationPolicy` (설계, 현재 코드는 `policy.ModelPolicy` 스텁) | ORC-009 · ORC-010 · ORC-011 | 정책은 자바 클래스이고 `-Dpolicy.class` → `ServiceLoader` → 내장 기본 구현 순으로 교체한다 — 최상위 ORC-010과 맞는다 (decision-12). 현재는 모델 선택만 맡는다. 역할 · 개수 · 시점은 Implementer 단독이라 아직 정책 대상이 아니지만, 인터페이스가 `AllocationPolicy`라 나중에 더해도 호출부는 그대로다 |
| Agent Spawner | `spawn.AgentSpawner`, `agent.AgentRunner` | ORC-001 · ORC-002 · ORC-023 | 별도 `claude -p` 프로세스, 프롬프트는 argv 원소 하나, stdin 닫음, `--bare` 없음. ORC-023(다른 프로바이더)은 `AgentRunner`의 다른 구현 자리로만 남는다 (1.02 P3) |
| Session Registry | `registry.SessionRegistry` (+ `spawn.AgentSpawner.terminate`) | ORC-003 · ORC-004 | 회수 한 호출 = 자손 확보 → 종료 → 제거 → 허가 반납, 멱등. 유예 시간은 500ms 상수(`TBD(최상위 Q-16)`). 정상 종료한 부모가 남긴 자손은 찾지 못한다(`TBD(최상위 Q-17)`) |
| 워크트리 격리 | `workspace.WorktreeManager` | ORC-012 | `../<repo>-wt/<id>` · `task/<id>` |
| 커밋 원장 | — | ORC-021 | 패키지 없음(최상위 3.03 §1의 `ledger/CommitLedger` 자리). 카드에 남기는 쪽은 `card.TaskCardSource`의 `recordAttempt` · `recordActual`이다 |
| 실행 흐름 | `Main` | ORC-022 · ORC-024 | `Main`은 `run <taskId>` 파싱까지다. 배선과 `runs.jsonl` 기록(최상위 3.03 §1의 `RunCommand`)은 패키지 없음 |
| (최상위 구성에 없음) | `card.TaskCardSource` | ORC-005 · ORC-021 | 카드 접근 포트. Token Budget(decision-6)과 claim(decision-9)이 이 저장소에서 더해진 것이라 최상위 구성 요소에 대응물이 없다 |

### 최상위 문서와 어긋나는 곳

- 최상위 BL-002는 기계 판독을 `task view --json`으로 하라고 한다. `BacklogClient`는 `--plain` 출력을 "제목 줄 + 대시 밑줄" 섹션 단위로 느슨하게 파싱한다(backlog 1.51.0 기준). `--json`의 readiness는 쓰지 않고 `isRunnable`이 상태와 직접 의존을 직접 판정한다.
- 최상위 3.03 §1은 Agent Spawner를 "다른 프로바이더 CLI로 교체 가능"으로 적는다. 이 저장소는 1.02 P3을 따른다.

## 동시성 모델

- 에이전트 하나마다 virtual thread 셋(stdout drain · stderr drain · 대기)을 쓴다. `Process.waitFor()`를 블로킹으로 써도 되는 코드 단순성이 virtual thread의 실익이다 (최상위 ADR-002).
- 동시 실행 상한은 `SessionRegistry`의 공정 `Semaphore` 허가 수다. 기본 1이고 생성자로만 바꾼다. 최상위의 `min(그래프 폭, 자원 실측)`(최상위 ADR-005)은 그래프 폭 계측이 없어 적용하지 않는다.
- 허가는 `admit`에서 얻고 `retire`에서만 반납한다. 호출자는 `admit` 직후부터 `try/finally`로 `retire`를 보장해, 스폰이 예외를 던져도 허가가 새지 않는다.
