# 3.03 컴포넌트 명세

> 작성 전

패키지 · 클래스마다 책임 · 공개 API · 구현하는 요구사항 · 테스트.

## 담을 내용

- [ ] 패키지별 절 — `backlog` · `workspace` · `spawn` · `agent` · `registry` · `policy` · `card` · 진입점 `Main`
- [ ] 절마다 구현하는 요구사항 ID와 테스트 클래스
- [ ] 남은 시그니처 스텁(`pending:` 카드)과 그 테스트의 `@Tag("pending")` 목록 — decision-11 시절 산출물, 해당 구현 카드가 정리한다(decision-13)
- [ ] 실행 가능 판정의 미병합 `task/<id>` 브랜치 검사(로컬 · 원격, `git cherry`)를 둘 자리와 그 테스트 — 구현은 AO-30 (최상위 ORC-005, decision-14, 1.02 P7)
- [ ] `card.TaskCardSource`의 `Attempt` · `Actual`에서 `commits`(트레일러 합계) 자리 — Q-18 전까지 비우고 `session`만 기록하며(AO-30), 계량 값이 정해지면 그 출력으로 채운다 (최상위 ADR-021, `TBD(최상위 Q-18)`, decision-8)
- [ ] 주의점 — 자손 프로세스 탐지 한계, backlog `--plain` 파서의 버전 의존
