# 3.03 컴포넌트 명세

> 작성 전

패키지 · 클래스마다 책임 · 공개 API · 구현하는 요구사항 · 테스트.

## 담을 내용

- [ ] 패키지별 절 — `backlog` · `workspace` · `spawn` · `agent` · `registry` · `policy` · `card` · 진입점 `Main`
- [ ] 절마다 구현하는 요구사항 ID와 테스트 클래스
- [ ] 남은 시그니처 스텁(`pending:` 카드)과 그 테스트의 `@Tag("pending")` 목록 — decision-11 시절 산출물, 해당 구현 카드가 정리한다(decision-13)
- [ ] 실행 가능 판정에 계획 승인 · 작업 순서 검사를 둘 자리(`backlog.BacklogClient` 또는 `card.TaskCardSource`)와 그 테스트 — 설계 요구이고 클래스 · 구현 카드는 미정 (최상위 ADR-022 · ADR-023, 1.02 P7)
- [ ] `card.TaskCardSource`의 `Attempt` · `Actual`에서 `commits`(트레일러 합계) 자리 — 토큰 계량 컴포넌트 출력으로 바꿀 대상 (최상위 ADR-021, `TBD(최상위 Q-18)`)
- [ ] 주의점 — 자손 프로세스 탐지 한계, backlog `--plain` 파서의 버전 의존
