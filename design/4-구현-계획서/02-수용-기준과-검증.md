## 담을 내용

- [ ] 요구사항 ID ↔ 수용 기준 · 비즈니스 규칙 ↔ 테스트(`@DisplayName` 표식 `<카드 ID>#<n>` · `<카드 ID>#B<k>`) 표
- [ ] 테스트 먼저 강제 — `require_test_first.py`(`testFirst` 설정), 훅이 보지 않는 것(Bash로 쓴 소스, 실제 빨강 여부), 표식을 요구하지 않는 `(수동)` AC(문서 전용 카드)
- [ ] 검증 명령 — `./gradlew test`(커밋 게이트), `./gradlew pendingTest`(남은 pending 테스트, decision-13 이후 새로 늘지 않음)
- [ ] E2E 스모크 — 실제 `claude`로 예상 토큰부터 실제치 병기까지
- [ ] 실측 항목 — peak RSS, 커밋 귀속분과 세션 총량의 차이
