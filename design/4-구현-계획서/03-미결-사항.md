# 4.03 미결 사항

> 작성 전

아직 정하지 않은 값과 질문. `Q-n`으로 식별한다.

## 담을 내용

- [ ] 미결 사항 표 — `Q-n` · 질문 · 걸린 요구사항 · 정할 방법
- [ ] 최상위 미결 사항 중 이 저장소에 걸린 것 — 회수 유예 시간(최상위 Q-16), 정상 종료 후 남은 자손(최상위 Q-17), 감시 방식(최상위 Q-10), `runs.jsonl` 스키마(최상위 Q-14), 토큰 계량 컴포넌트(이름 미정)의 측정 방식과 실제치를 읽는 계약(최상위 Q-18), 완료 기록 형식(최상위 Q-20)
- [ ] 헤드리스 기본 권한 모드, `DefaultAllocationPolicy` 상수(토큰 구간 · 모델)의 근거
- [ ] 미병합 `task/<id>` 브랜치 판정의 세부 — 원격 브랜치를 보기 전에 언제 fetch하는가, `git cherry`의 기준 브랜치(로컬 main · 원격 main), 남은 실패 브랜치를 누가 지우는가 (최상위 ORC-005, decision-14)
